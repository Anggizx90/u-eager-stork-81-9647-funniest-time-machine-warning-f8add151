An entry for the [make.fun](https://make.fun/bounty/u-eager-stork-81-9647-funniest-time-machine-warning-f8add151) bounty **"Funniest Time Machine Warning Label"**.

The program writes one warning label — the funniest one-line warning for a
time machine, 120 characters at most — to `/output/entry.txt`:

> WARNING: Do not introduce yourself to ancestors. One will marry your grandmother, and you will be your own grandfather.

Why this line: it is a genuine warning label in form (WARNING + imperative);
the hazard is the classic grandfather paradox, but the joke is the
consequence, stated as a dry fact in the last six words — you become your own
grandfather. Nothing is wasted: 119 of the 120 allowed characters, the
surprise saved for the very end. See `candidates.md` for the 12 drafts and
the head-to-head that picked this one.

## Run it

Requires Node 22.18 or later:

```sh
node main.ts
cat /output/entry.txt
```

`MAKEFUN_OUTPUT_DIR` may be set to override the output directory
(default `/output`).
